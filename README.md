## ✨ Features

- 📸 **Upload any photo** — JPG, PNG, or HEIC (iPhone photos supported)
- ⚡ **Real-time preview** — card updates as you type
- 🎨 **Cyberpunk × Coastal India design** — dark navy, electric teal, saffron gold
- ⬇️ **Download as PNG** — high resolution (3× render)
- 𝕏 **Share to X** — pre-filled caption with `#FrameInGoa`
- 📱 **Mobile friendly** — works on any device
- 🔓 **No login required** — fully client-side, zero backend

## 🛠️ Stack

Pure HTML + CSS + Vanilla JS — single file, no build step.

- [`html2canvas`](https://html2canvas.hertzen.com/) — card → PNG rendering
- [`heic2any`](https://github.com/alexcorvi/heic2any) — HEIC conversion
- Google Fonts — Bebas Neue · Space Grotesk · JetBrains Mono · Noto Sans Devanagari

## 🚀 Run Locally

```bash
# Just open index.html in your browser — or serve with Python:
python -m http.server 8080
# → http://localhost:8080
```

## 📤 Deploy

Drag `index.html` to [Netlify Drop](https://app.netlify.com/drop) for an instant live URL.
